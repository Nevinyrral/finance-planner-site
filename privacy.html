Privacy policy

Finance planner · last updated 10 November 2026

Finance planner is a personal tool that runs on its owner's own computer. Its only user is its owner, and the only Google account it ever connects to is the owner's own.

What it accesses

With the owner's approval, the tool has read-only access to the owner's Gmail account. It asks Gmail only for alert emails from the bank addresses the owner has listed, and reads from each one the date, the merchant or other party, and the amount of a movement.

How that information is used

Only to show the owner their own recent spending in a private dashboard and to sort each movement into a budget category.

Where it is kept

Copies of those emails, and the movements read from them, are stored on the owner's computer. They are not uploaded to any server run by this project, because there is none.

What is shared

  • Nothing is sold, and nothing is shared with advertisers or data brokers.
  • Nothing is used to develop or train machine-learning models.
  • When a movement cannot be sorted automatically, the tool can send the owner a message through the owner's own Telegram bot that names the merchant or other party and the date, so the owner can choose a category. That message goes only to the owner's own chat and never includes an amount or an account number.

Google's policy

The tool uses information received from Google APIs only to provide the features described on this page, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Keeping and removing it

The stored copies stay on the owner's computer until the owner deletes them. The owner can withdraw the tool's access at any time at myaccount.google.com/connections.

Questions

Finance planner is a private, non-commercial project with no other users. Questions about this page can be raised on the repository that hosts it.
